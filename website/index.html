Does SeePal work without internet? SeePal 可以离线使用吗？

After setup, the dashboard runs locally and keeps core features online-free.

完成设置后，核心功能本地运行，不会依赖云端服务。

What coding tools can I use? 我可以搭配哪些编程工具？

SeePal focuses on Codex-style thread history and local Git context in this phase.

当前版本聚焦 Codex 风格会话记录与本地 Git 上下文。
